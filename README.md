#  AI Object Detection & Tracking

An AI-powered Object Detection and Tracking web application built using **Python**, **Streamlit**, **YOLOv8**, and **OpenCV**.

##  Features

-  Image Object Detection
-  Live Webcam Detection
-  Real-time Object Tracking using YOLOv8
-  Object Labels
-  Live Detection Statistics
-  Adjustable Confidence Threshold
-  Simple Streamlit Interface

##  Technologies Used

- Python
- Streamlit
- YOLOv8 (Ultralytics)
- OpenCV
- Pillow

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/AI_Object_Detection.git
```

2. Open the project folder

```bash
cd AI_Object_Detection
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```

## 📸 How to Use

- Upload an image for object detection.
- Enable **Start Webcam** for live detection.
- Adjust the confidence threshold using the sidebar.
- View detected object labels and live statistics.
